เปิดแอปตรวจเช็ครถ
⚠️ ตอนนี้เปิดอยู่ในแอป LINE / Facebook
แอปพวกนี้ไม่มีเมนูเพิ่มไอคอน ต้องเปิดหน้านี้ใน Safari / Chrome ก่อน เปิดในเบราว์เซอร์
หรือกดค้างที่ลิงก์ แล้วเลือก "เปิดในเบราว์เซอร์" / คัดลอกลิงก์ไปวางใน Safari หรือ Chrome

📲 เพิ่มไอคอนไว้บนหน้าจอมือถือ

  1. เปิดหน้านี้ด้วย Safari (ไม่ใช่ใน LINE / Facebook)
  2. แตะปุ่มแชร์ ⬆︎ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) ที่แถบด้านล่าง
    iOS 26: ถ้าไม่เห็น ให้แตะ ⋯ ที่มุมขวาล่างก่อน แล้วแตะ แชร์
  3. เลื่อนรายการลงแล้วแตะ เพิ่มไปยังหน้าจอโฮม
    ถ้าไม่มี ให้เลื่อนลงล่างสุด → แก้ไขการทำงาน → กด ➕ ที่ "เพิ่มไปยังหน้าจอโฮม"
  4. แตะ เพิ่ม มุมขวาบน
ใช้ Chrome บน iPhone ก็ได้: แตะ ⬆︎ ที่แถบที่อยู่ด้านบน → เพิ่มไปยังหน้าจอโฮม
  1. เปิดหน้านี้ด้วย Chrome
  2. ถ้ามีปุ่มสีส้ม ➕ เพิ่มไอคอนลงหน้าจอ ด้านบน แตะได้เลย
  3. ถ้าไม่มี ให้แตะเมนู ⋮ มุมขวาบน
  4. แตะ เพิ่มลงในหน้าจอหลัก หรือ ติดตั้งแอป (บางรุ่นอยู่ใน แชร์)
  5. แตะ เพิ่ม / ติดตั้ง
Samsung Internet: แตะ ☰ ด้านล่าง → เพิ่มหน้าไปที่ → หน้าจอหลัก
แตะไอคอน "ตรวจเช็ครถ" บนหน้าจอ แล้วระบบจะเปิดแอปให้ทันที (ล็อกอินครั้งแรกครั้งเดียว ระบบจำไว้ 30 วัน)
